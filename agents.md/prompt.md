# Task: Create Solar System Website Homepage

## Objective

Create the homepage for the solar system information website based on the provided requirements.

The goal is to create a visually appealing and informative frontend that can later be integrated with JavaScript functionality.

---

# Read Before Starting

Follow these files:

- Copilot-instructions.md
- prompt.md
- requirements.md

---

# Responsibilities

You are responsible for:

- Creating HTML structure
- Creating CSS styling
- Creating the visual layout
- Creating reusable UI components

---

# Do Not

Do not:

- Write JavaScript code
- Add script tags
- Add inline JavaScript
- Implement interactions
- Create features not listed in requirements

---

# Implementation Requirements

The homepage must include:

- Website title
- Introduction to the solar system
- Short description
- Fun facts section
- Overview of celestial bodies
- Solar system imagery
- Navigation tabs for celestial bodies

The design should:

- Have a consistent visual style
- Use realistic/scientific space imagery
- Maintain the same art style across all images
- Be responsive for desktop and mobile

---

The HTML must be prepared for future JavaScript implementation.

Include:

- Meaningful IDs

- Clear component structure
