# Overview

Create the frontend/UI of a website that gives information about the sun and all the planets in our solar system.

---

# Goals

The website should: 
- be informative
- be easy to navigate 
- have a 40/60 balance of both images and words respectively
- not have too much information per page (not too cramped)


--- 

# pages

## Home Page

The home page is just an introductory page about our solar system as a whole.

Must include: 
- Website title
- short description
- a few fun facts
- an overview of the celestial bodies inside our solar system
- many images that match what the website is about (our solar system)
- the images must be similar in style and art:
    - example: if one picture is of the sun is a realistic art or photograph, another picture cannot be a cartoon image of the planet earth
- must have different tabs for each planet or celestial body included in our solar system


## Celestial Body Pages

The website must include separate pages or sections for each celestial body included in the solar system.

Each celestial body must have its own dedicated tab.

When a user selects a celestial body tab:

- The user should be taken to the corresponding celestial body page.
- The page must display detailed information about that celestial body.
- The page must include:
    - Name/title
    - Description
    - Important facts
    - Scientific information
    - Relevant images matching the website's visual style

Users must be able to navigate between all celestial body tabs without returning to the home page.

Navigation must allow users to:

- Move from one celestial body page to another.
- Return to the home page.
- Easily switch between different planets or celestial bodies at any time.

The navigation system should remain consistent across all pages.

# Navigation Design

The website should use a tab-based navigation system.

Each tab represents a celestial body (Sun, Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune, Moon, etc.).

Selecting a tab should dynamically display or navigate to the selected celestial body's information page.

The active tab should be visually identifiable so users know which celestial body they are currently viewing.
